# Support

## Bug Reports, Feature Requests and Questions

We accept these on [GitHub Issues]({{ site.issues_url }}) (a GitHub account is required). You may write in English or Japanese.

- [Report a bug]({{ site.issues_url }}/new?template=bug_report.yml)
- [Request a feature]({{ site.issues_url }}/new?template=feature_request.yml)
- [Ask a question]({{ site.issues_url }}/new?template=question.yml)

Before opening a new issue, please check whether [an existing issue]({{ site.issues_url }}?q=is%3Aissue) already covers it. If so, adding a 👍 or a comment there helps us prioritize.

### Do Not Post in Issues

Issues are **public**. Please do not include:

- Email addresses, account IDs or passwords
- Server addresses, user names, private keys or passphrases
- Note content, file names, folder paths or anything else you do not want to make public

If you attach screenshots or logs, make sure none of the above appears in them.

## Private Inquiries {#contact}

Please send the following by email instead of opening an issue:

- Account deletion (see the [Privacy Policy]({{ '/en/privacy/' | relative_url }}#account-deletion) for the procedure)
- Requests to access, correct or delete your personal information
- Inquiries about purchases and licenses (refunds follow the procedure of the Store where you purchased)
- Security issues (vulnerabilities)
